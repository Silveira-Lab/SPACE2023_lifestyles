# SPACE2023_lifestyles
Ecology of viruses in meromictic lakes with a focus on host association and lifestyles. The data in this studi will include: 43 metagenomes (3 lakes, 3 depths, 5 replicates), 33 metatranscriptomes (3 lakes, 3 depths, 5 replicates), and 2 Hi-C read libraries (Mahoney and Poison chemoclines). Metagenomes are missing from Poision and Mahoney chemoclines. Transcritomes missing include: Lime Blue - (2) bottom; Mahoney - (1) surafce, (1) chemocline, and (5) bottom, and (1) each depth of Poision. 
## Sample used in analysis
### Metagenomes & MAGs
*Need input from NV on extraction methods.* All metagenomes were processed according the JGI's standard workflows including QC of reads, assembly, and binning [(Clum et al, 2021)](https://journals.asm.org/doi/10.1128/msystems.00804-20). MAGs were quality controlled beyond JGI's workflow by running CheckM2 (v1.0.1) (Uniref100) and retaining only Medium and High Quality MAGs (>=50% complete & <=10% contam; >=90% complete & <=5% contam). A set of dereplicated MAGs was created using [dRep](https://github.com/MrOlm/drep) (v3.5.0) with the recommended settings. Dereplicated MAG taxonomy was predicted using the [GTDB-tk](https://github.com/Ecogenomics/GTDBTk) (v2.4.1) classify workflow with the r220 database. Open reading frames were predicted using [prodigal](https://github.com/hyattpd/Prodigal) (v2.6.3). Functional annotation of predicted genes in the dereplicated MAGs was done with [MetaCerberus](https://github.com/raw-lab/MetaCerberus) (v1.2.1).
### Transcriptomes
All transcriptomes were processed according to [Varona et al, 2025](https://microbiomejournal.biomedcentral.com/articles/10.1186/s40168-025-02085-y).
### Hi-C Sequencing
Hi-C libraries were prepared for the Mahoney and Poison lake Chemoclines with the Phase Genomics ProxiMeta Hi-C v4.0 Kit, briefly, DNA within cells was crosslinked with formaldehyde, digested with Sau3AI and MlucI, and ligated to form chimeric DNA molecules, which were then pulled down with streptavidin beads ([Varona et al, 2024](https://academic.oup.com/ismej/article/18/1/wrae240/7918320); [Press et al, 2017](https://www.biorxiv.org/content/10.1101/198713v1); [Uritsky et al, 2021](https://www.biorxiv.org/content/10.1101/2021.06.14.448389v1.abstract)). Reads were downloaded from Phase Genomics. Cutsites from restriction enzymes were identified and digested *in silico* using the cutsite feature of [hicstuff](https://github.com/koszullab/hicstuff) (v3.2.4). Hi-C linkages and MAGs were generated from contacts using the [metaTOR](https://github.com/koszullab/metaTOR) (v1.3.7). The pipeline was ran on the Hi-C reads and scaffolds generated by JGI for the two sampling location. Each loaction was process (5) separate times for each replicate metagenome.

MAGs generated by metaTOR were quality controlled using the methods and cutoffs used in the metagenomes section.

## Viral population identification and annotation
Viral contigs were predicted using [Genomad](https://github.com/apcamargo/genomad) (v1.8.1) database downloaded 1/3/24. Viral prediction using the end-to-end pipeline was done separately on 1) concatenated metagenome scaffolds, 2) concatenated metagenome MAGs, 3) Hi-C MAGs and 4) concatenated metatranscriptome contigs. Metatranscriptome viruses were copied from the [Varona et al, 2025](https://microbiomejournal.biomedcentral.com/articles/10.1186/s40168-025-02085-y) study but they were processed as described here. 

[COBRA](https://github.com/linxingchen/cobra) (v1.2.3) was used to elongate viral contigs from non-HiC metagenomes in an attempt to better assemble prophages. The inputs for COBRA were created using [minmimap2](https://github.com/lh3/minimap2) (2.28-r1209), [samtools](https://www.htslib.org/) (1.21), and [CoverM](https://github.com/wwood/CoverM) (v0.7.0). 

Viruses larger than 2,500 bp were clustered into vOTUs at 95% ANI and 85% coverage using the helper scripts and examples provided by [CheckV](https://bitbucket.org/berkeleylab/checkv/src/master/) (v1.0.3).

Viral contigs were quality controlled using CheckV's end_to_end pipeline. The quality_sumary.tsv was then used to choose contigs that met the following criteria: 
1. had >= 1 viral gene and was >= 10 kbp
2. was medium or high quality, had >= 1 viral gene, and < 50% contamination
3. had >= 1 viral gene, had no host genes, and was < 50% contamination

 Viral representative sequences were annotated using MetaCerberus. All of the models were used for annotation and the *--meta* option was invoked.
## Viral lifestyle identificaiton
The following methods were used to identify prophages or temperate viruses using the vOTU representative sequences. The results of these analysis were aggregated into a single tsv file.
1. VIBRANT - lysogenic
2. Hallmark functions - lysogenic
3. [BLASTn](https://www.ncbi.nlm.nih.gov/books/NBK279690/) (v2.16.0) search of phages against MAGs - prophage
4. CheckV prophage identification - prophage
5. Genomad prophage identification - prophage

Functional hallmarkes were identified by searching MetaCerberus results for: integrase, recombinase, transposase, excisionase, CI/Cro, Phage repressor, and ParAB.

BLASTn searches were done by performing a BLASTn search of the vOTU representative sequences against a databse of all the MAG contigs (without dereplication of MAGs). Only hits with 95% identity, 100% coverage, and 500 bp flanking regions were considered prophages.
## Virus-Host Prediction
The following methode were used to identify virus host pairs which were aggregated into a single tsv file.
1. Hi-C bins - contacts combined with viral prediction using Genomad
2. [iPhop](https://bitbucket.org/srouxjgi/iphop/src/main/) (v1.3.3) - *in silico* virus host matching
3. BLASTn of phages against MAGs
4. CRISPR spacer matches from spacers found in MAGs 

Hi-C MAGs were not dereplicated or processed beyond CheckM2 qualtiy control cutoffs prior to predicting viral contigs.

MAGs were added to a custom iPhop database containing the typical iPhop database with our MAGs, per iPhop's documentation. Briefly, we removed any contig that contained a viral sequence from the MAGs, we ran GTDB-tk denovo_wf, and added the MAGs to the iPhop database. We included all MAGs (without dereplication) in an attempt to include as much microdiversity as possible in the set of host genomes.

The BLASTn identification of hosts was done in the same manner as stated in the prophage identifcaiton step.

CRISPR spacers were predicted from the set of MAGS without viral contigs (and not dereplicated) using [Minced](https://github.com/ctSkennerton/minced) (v0.4.2) with the *spacers* option. Spacer fasta files were concatanated and queried against a database of the vOTU representative sequences using BLASTn. Only hits with 100% identiy and 2 or fewer mismatches were considered matches.
## Viral and MAG abundance estimates
Reads and transcripts were mapped back to vOTU representative sequences and dereplicated MAGs using [BBMap](https://archive.jgi.doe.gov/data-and-tools/software-tools/bbtools/) (v39.08). RPKM and coverage statistics were output for each metagemome/metatranscriptome mapped using the flags provided by BBMap. BAM files were converted to SAM files, sorted, and indexed using [samtools](https://www.htslib.org/) (v1.21).
